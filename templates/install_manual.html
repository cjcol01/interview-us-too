Direct install

Install InterviewAce without the Chrome Web Store

If the Web Store listing is ever down for review or unavailable, you can still install the exact same extension directly. It takes about a minute and only needs to be done once.

Download the extension

A zip of the same code that ships on the Web Store.

Download .zip Trouble downloading? Try the mirror
1

Unzip it

Extract the downloaded zip anywhere on your computer — a folder called interviewace-extension will appear. Keep that folder where it is; Chrome reads the extension directly from it, so don't delete it after installing.

2

Open Chrome's extensions page

Chrome blocks links from opening this page directly, so copy the address below and paste it into your address bar.

chrome://extensions
3

Turn on Developer mode

Toggle Developer mode on in the top-right corner of the extensions page. Chrome will show a banner saying developer-mode extensions may be less safe. This is annoying, but Chrome shows it for every extension installed outside the Web Store — it's not a sign anything is wrong with ours.

4

Load unpacked

Click Load unpacked (top-left) and select the interviewace-extension folder you unzipped in step 1. The extension installs immediately — no restart needed.

5

Continue setup

Pin it via the puzzle-piece icon in Chrome's toolbar, then head back to onboarding to connect it to your account.

Continue to onboarding →
If it stops responding after a Chrome update: Chrome occasionally disables unpacked extensions when it updates itself. Go back to chrome://extensions and toggle it back on — your setup and hotkeys aren't affected.

These steps are written for Chrome. Edge, Brave, and other Chromium browsers use the same chrome://extensions flow. Questions? Email us.
